# 和牛巡禮 wagyu-meguri

把你吃過的和牛品牌標在 3D 日本地圖上。貼上清單，網站會自動對應到日本 47 都道府縣；也收錄全日本 224 個品牌牛供參考。

**網站：** https://planktonthai.github.io/wagyu-meguri/

## 怎麼用

1. 打開網站，按「匯入清單」。
2. 貼上你吃過的和牛，一行一筆，格式是「地區：品牌」：

   ```
   北海道：白老牛
   山形：米澤牛｜日期 2026-04-12｜評分 5｜地點 米澤牛亭
   山形：山形牛、鷹山牛
   九州：九州王和牛
   宮崎牛

   # 想吃
   三重：松阪牛
   ```

3. 按「預覽對應結果」，確認每個品牌對到哪個縣，再按「確認匯入」。

網站預設只放一筆「北海道：白老牛」當範例。

### 格式規則

- 冒號全形「：」、半形「:」都可以，也接受逗號或 Tab，所以 CSV 檔可以直接上傳。
- 同一縣有多個品牌時，可以寫在同一行，用「、」分開。
- 地區寫法很彈性：「山形」「山形縣」「山形県」都會對到山形；也接受「九州」「東北」「關西」這類大區。
- 可以只寫品牌：網站會用全日本品牌資料庫找出縣，例如「宮崎牛」會自動放到宮崎。
- 中文和日文寫法都比對得到，例如米澤牛和米沢牛、橄欖牛和オリーブ牛、神戶紅酒牛和神戸ワインビーフ。
- 第一行如果是「地區：品牌」標題列，會自動略過。
- 品牌後面可以用「｜」接個人欄位，每個都可以省略，順序不限：`日期`（2026-04-12 或 2026-04）、`評分`（1～5，也可以寫 ★★★★★）、`地點`、`產地`、`品種`、`備註`。
- `# 想吃` 這一行以下的品牌會放進想吃清單；`# 吃過` 可以切回吃過清單。

### 對應結果

| 狀態 | 意思 |
|---|---|
| 新增 | 直接加到地圖 |
| 新增・請確認 | 已加入，但需要你看一下。例如寫「山形：松阪牛」，網站會照你寫的放在山形，同時提醒資料庫裡的松阪牛在三重 |
| 待確認 | 找不到縣，例如縣名打錯、資料庫也沒有這個品牌。這些品牌會放在清單上方，用下拉選單選好縣，就會出現在地圖上 |
| 移到吃過 | 原本在想吃清單，這次寫在吃過的部分 |
| 補上資料 | 已經在清單裡，這次多寫了日期、評分等欄位，會補進去 |
| 略過 | 已經在你的清單裡 |

## 其他功能

- **分享**：產生分享連結，朋友打開就能看到你的地圖，也能一鍵存成自己的清單；還可以下載一張 1080×1350 的分享圖片，適合 IG、LINE
- **想吃清單**：在「全日本品牌」按「想吃」就會加入，地圖上用淡綠色標示；吃到之後按「吃過了」移過去
- **收集進度與成就**：顯示已解鎖幾個縣、吃過資料庫裡多少品牌，以及 16 個成就徽章，例如日本三大和牛、九州・沖繩制霸、47 縣全制霸
- **個人紀錄**：每個品牌可以記吃的日期、評分和地點
- **新增品牌**：一筆一筆手動加，輸入品牌名稱後，如果資料庫只對到一個縣，會自動幫你選好
- **匯出清單**：輸出同樣的「地區：品牌」格式，可以複製或下載成 .txt，換裝置時再匯入
- **檢查重複**：找出清單裡寫法不同、其實是同一品牌的項目
- **清空資料**：刪除整份清單，從零開始；清空後可以按「載入範例」
- **兩種檢視**：「我吃過的」與「全日本品牌」，縣的顏色越深代表品牌越多
- **3D／2D 地圖**
  - 拖曳移動、滾輪或雙指縮放（以游標位置為中心）、雙擊放大
  - 右鍵或 Shift＋拖曳旋轉；指北針一鍵轉回正北
  - 點縣市或地區按鈕，鏡頭會平滑飛過去
- **深淺色切換**：淺色、深色、跟隨系統
- **加入主畫面**：手機瀏覽器選「加入主畫面」，就能像 App 一樣打開；離線也能看清單和平面地圖

你的清單只存在自己的瀏覽器，不會上傳到任何地方。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 網站本體，由 `build.py` 組裝產生，**不要直接改** |
| `sw.js` | 離線快取（service worker），由 `build.py` 產生 |
| `manifest.webmanifest`、`icons/` | 加入主畫面用的名稱與圖示 |
| `og.png` | 在 LINE、FB 分享網址時顯示的預覽圖 |
| `src/` | 原始碼：`head.html`、`page-head.html`（樣式）、`body.html`、`app.js`、`map3d.js`、`loader.js`、`sw.js`、`sw-register.js` |
| `data/japan-wagyu-brands.json` | 全日本品牌牛資料庫（縣代碼、品牌名、品種、備註） |
| `data/brand-notes.json`、`data/brand-notes-wide.json` | 品牌介紹，名稱對得上時顯示在卡片上 |
| `data/paths.json`、`data/centroids.json` | 47 都道府縣的地圖形狀與圓章位置 |
| `data/example-my-wagyu.txt` | 匯入格式範例 |
| `data/日本和牛品牌清單.xlsx` | 品牌清單的試算表版，由 `tools/make_xlsx.py` 產生 |

## 修改網站

1. 改 `src/` 或 `data/` 裡的檔案。
2. 執行 `python3 build.py`，會重新產生 `index.html` 和 `sw.js`。
3. 提交並推送到 `main`，GitHub Pages 約 1～2 分鐘後更新。

改了資料庫後，可以執行 `python3 tools/make_xlsx.py` 重新產生試算表（需要 `openpyxl`）。
